# 档案页重构 + 疫苗追踪

**Date**: 2026-06-02
**Status**: approved

## 目标

重构首页和档案页的职责划分，新增疫苗接种追踪功能。

## 页面职责

### 首页 (HomeScreen)
日常使用入口，侧重"今天做什么"：
- 宝宝信息卡片
- AI 智能工具网格（4 个）
- 今日速览（2 餐 / 8.2h / 85 分）
- 最近的喂养记录、睡眠记录、便便记录（从档案页迁入）
- 快速添加记录 FAB（从档案页迁入）

### 档案 (RecordsScreen)
趋势和统计，侧重"宝宝长得怎么样"：
- 疫苗提醒卡片（下一针时间）
- 生长曲线（身高/体重）
- 疫苗接种完整时间表
- 周均睡眠/喂养/便便统计
